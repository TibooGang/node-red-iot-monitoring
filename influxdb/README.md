# InfluxDB

InfluxDB используется в проекте для хранения временных рядов, получаемых в процессе испытаний батареи топливных элементов.

Node-RED передаёт в базу обработанные значения измеряемых параметров с временной меткой и уникальным тегом датчика.

## Структура данных

Каждое измерение содержит:

- значение параметра (`value`);
- тег датчика (`sensor`);
- временную метку (`timestamp`).

Примеры тегов:

- `Flow_H2` — расход водорода;
- `Pressure_H2` — давление водорода;
- `Temperature_Inlet_H2` — температура водорода на входе в БТЭ;
- `Flow_Air` — расход воздуха;
- `Pressure_Air` — давление воздуха;
- `Current` — сила тока;
- `Voltage` — общее напряжение;
- `Power` — расчётная электрическая мощность.

Полученные временные ряды используются Grafana для построения графиков и мнемосхемы испытательной системы.
