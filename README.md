# Node-RED IoT Monitoring System

Система сбора, хранения и визуализации данных технологических процессов на базе Node-RED.

Проект демонстрирует построение полного контура мониторинга оборудования: получение данных по промышленным протоколам, сохранение измерений во временно́й базе данных и отображение параметров на информационных панелях.

## Реализованный функционал

✔ Сбор данных с промышленных устройств по Modbus TCP

✔ Сбор данных с устройств по Modbus RTU через RS-485

✔ Сохранение телеметрии во временну́ю базу данных InfluxDB

✔ Построение дашбордов в Grafana

✔ Выполнение пользовательских расчётов в реальном времени

✔ Отображение текущих и архивных данных

✔ Масштабирование на несколько устройств и десятки каналов измерений

## Технологии

* Node-RED
* Modbus TCP
* Modbus RTU
* InfluxDB
* Grafana
* JavaScript
* Industrial Data Acquisition & Monitoring

## Область применения

Мониторинг показателей испытательных стендов, технологического оборудования и промышленных систем сбора данных с построением информативных дашбордов.

## Структура проекта

- `node-red/` — логика сбора, обработки и маршрутизации данных
- `influxdb/` — описание хранения телеметрии во временной базе данных
- `grafana/` — описание визуализации и примеры информационных панелей
- `screenshots/` — примеры работы системы
